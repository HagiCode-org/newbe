.Net Conf: Focus on Microservices 是 .Net Conf 社区在 2020 年 7 月 30 日举办的线上分享活动。整个活动视频长达近 10 个小时。今天我们来看看都发生了什么。

<!-- more -->

## 章节汇总

本次分享由十多位来自全球的资深技术专家在线分享，涵盖了当前 .Net 在微服务领域的利器。包括有以下这些内容：

1. .Net 最新特性与微服务
1. 为何关注微服务（Why You Should Care About Microservices）
1. 保持技术敏锐（Stay Sharp）
1. 使用 Steeltoe 开启 .NET 微服务旅程（A Journey into .NET Microservices with Steeltoe）
1. Orleans 在微软中的应用（Orleans at Microsoft）
1. DARP 助力您的 .NET 微服务（Adding a Little DAPR to Your .NET Microservices）
1. Tye 让您快乐开发微服务（Developing and Deploying Microservices With 'Tye'）
1. 不仅只有 REST 和 RPC，还有异步事件和消息模式（Beyond REST and RPC：Asynchronous Eventing and Messiging Patterns）
1. 微服务、DDD 和 E FCore（The Intersection of Microservices, Domain-Driven Design and Entity Framework Core）
1. gRPC 为 .NET 微服务带来更高性能（Build High-performance Microservices with gRPC and .NET）
1. 微服务 DevOps（DevOps）
1. 微服务中的 API 管理以及 Azure 上的 Functions（API Communication in Microservices With Azure API Managerment and Azure Functions）
1. 如何通过 .NET 5 和 K8S 来实现单体式到微服务演进（Evolving .NET Framework Monoliths with .NET 5 and Kubernetes）
1. 将 .NET Frameowkr Web 应用程序迁移到 Azure 上（Migrating .NET Framework Web Apps to Azure）
1. 使用 VS 和 K8S 实现微服务开发和调试（Building & Debugging Microservices with Kubernetes & Vistaul Studio）
