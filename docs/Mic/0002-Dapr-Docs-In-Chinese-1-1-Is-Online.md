## 文库更新亮点

Dapr 使用 sidecar 架构，与应用程序一起作为单独的流程运行，包括服务调用、网络安全和分布式跟踪等功能。 这经常会引发一个问题 - Dapr 与服务网格解决方案（如 Linkerd 、Istio 和开放式服务网格 （OSM） 相比如何？

https://dapr-cn.gitee.io/concepts/service-mesh/

Tye 是一个让开发、测试和部署微服务和分布式应用变得更容易的工具。Project Tye 包括一个本地编排器，使开发微服务更容易，并能够以最少的配置将微服务部署到 Kubernetes。

https://dapr-cn.gitee.io/developing-applications/sdks/dotnet/dotnet-development/dotnet-development-tye/

docker-compose 是 Docker Desktop 中包含的一个 CLI 工具，你可以用它来同时运行多个容器。它是一种将多个容器的生命周期自动化在一起的方式，并为针对 Kubernetes 的应用提供类似于生产环境的开发体验。

https://dapr-cn.gitee.io/developing-applications/sdks/dotnet/dotnet-development/dotnet-development-docker-compose/
