## 为什么要创建频道？

![解决什么问题](/images/20220117-001.png)

**专业性，“你可以在我们群里面钓鱼，因为都是水”**你肯定加过非常多的这种叫什么技术交流群。你会发现这个技术交流群那除了技术，那是什么都讲。讲股票，讲相亲，讲房产，甚至交流钓鱼（因为我们本来就是钓鱼技术交流群，手动狗头）。但是呢，我们就不说技术相关的内容，这是一个非常明显的情况。那当然我们不排除，有存在一些技术技术交流非常深入的这种群，但是他毕竟是少数的，大部分群呢，还是偏水一点。这是什么原因呢？我们不知道，但是这是一个问题，我们后续会有一些方案来尝试解决这个问题。

**重复性，“明明很简单的问题，总有人问了一遍又一遍”**重复性是说，比如第一天可能有朋友进来说：“哎，群里们的朋友们有没有人帮我解决一下，为什么我初始化的时候失败呀？”，然后这个时候有个大牛站出来说：“哦，我的朋友，这非常简单哦，我知道了，你只是因为 GitHub 上不去而已”。然后那个朋友说：“哎，那怎么解决呀？”然后他们交流一段时间他就知道了怎么解决。然后第二天又有人进来又问了一个同样的问题，这不是很尴尬吗？然后他又回答了一遍。到第三天，又有人问一样的问题，那第三天：“哎，你去搜索一下吧，最近有博客写了这个问题”这是一个什么原因呢？实际上就是因为即时通讯软件，就是 QQ，微信这些软件它无法长效地保留一个讨论结果。即时通讯软件里面，上句不接下句，后面没人没保存，后面人也不会去翻那些历史记录，那自然就丢失了，那相对呢，就带来了重复性，这也是一个问题。

**针对性，“综合性咨询网站内容过于繁杂”**我们刚才聊的其实都是关于这个即时通讯软件的问题，我们水群，重复之类的问题。而另外一类，你在了解一个技术内容的时候，还有一种方案就是你可以通过博客网站，资讯网站，比如说开源中国，你可以了解到，一些关于 Dapr 的内容，但是呢，由于这些博客或者说 OS China，他们并不是专门针对 Dapr 创建的，所以他们上面会放非常多，不是 Dapr 内容。那如果你要从这些资料当中过滤出你想要的，正好是比如说 Dapr 教程，Dapr 的原理性分析，最近的更新计划，那就比较困难。所以说综合性的这种资讯网站。它的针对性不是那么强，我们需要的是一个，垂直领域之内更小的网站来综合这些信息。高内聚信息之后，那么朋友获取许这些信息的方式就更加的简单了。

**容纳性，“快给群主充值，群主的 SVIP 要到期了”**这个其实也可以叫流动性。首先比如说你像 QQ 群，微信群它都有一个人数的限制。QQ 群，你首先得充钱对吧？充钱才能变强。你要从 500 人升到 1000 人，需要一个 SVIP ，你用微信群的话你会发现，200 个人之前我还可以通过二维码分享，200 个人之后我就发现没办法了。需要邀请，邀请就很麻烦，那这些一定程度上阻碍了容纳性的大小。另外一方面呢你要加入这些群，找到这些群非常之困难。这一定程度上限制的容纳性与流动性。

所以，综上所述就是我们今天想要寻找一个软件或者方式来解决这四个问题。

## 我们为什么选择 QQ 频道

这其实就是一个类似 Discord 的软件。

### 子频道

![子频道](/images/20220117-002.png)

QQ 频道可以设置子频道，那么设置子频道实际上解决什么问题呢？

第一个是专业性。

之所以以前这些群就是各种水群，他一个很关键的因素是这种日常的沟通，跟专业的技术讨论，混在一起，那久而久之，大家又发现，诶，怎么天天都在水群啊？这个群就越来越水，越来越水。那怎么办呢？我们可以专门设置子频道，这个频道专门水，爱水的朋友继续划水，那个频道专门讨论安装的问题，那个频道专门讨论 tooling ，或者专门讨论 actor 或者 community call，或者某个社区项目。比如说在 dotnet 上有一些非常经典的社区项目，比如说像 Masa，一个与 Dapr 有关的开发框架。或者说你也可以讨论我们的中文文档翻译呀。那我们可以专门建立一个子频道。所以说通过子频道的方式一定程度上解决了专业性的问题。

### 发帖

![发帖](/images/20220117-003.png)

实际上我们知道长效保存机制的最终体现就是以文本文档，博客的方式沉淀下来，这就是一个长效保存机制。这种长效保存机制，一种方式就是发帖。很多朋友们玩游戏都知道，如果玩一个游戏，比如说，泰拉瑞亚呀，或者说，非常复杂的戴森球计划呀，我怎么去找攻略呢？要么去游戏网站，要么进行贴吧。贴吧里面就是一种类似像博客一样的，他将讨论过的内容变成文本，保存下来。

那频道当中的呢？帖子也是一样的，你可以在专门的频道当中创建，比如说自由投稿的栏目，那么这个栏目当中，大家可以投稿一些最近的最新的视频教程，最新的框架更新内容，设计思路这些内容。那另外，比如说有人遇到一些难题对吧？遇到问题，你可能在群里面某些只平台当中聊天可以解决，但聊天完之后，比如说我们刚才前面提到的问题，你安装初始化的时候，不是会遇到一些难题吗？完全可以把这个问题写成一个帖子放在频道的当中，那下次有人在问这个问题的时候，你直接引用那边帖子，他就不需要再去搜索，也不需要博客，全部都在这个频道上。

### 日程管理

![日程](/images/20220117-004.png)

那除此之外呢，QQ 频道有个日程管理。在日程管理当中，项目方，比如说某些框架的作者，或者视频 up 主，他们完全可以将自己的计划时间，比如说在某年某月某日某希望做一次线上的分享活动，那我可以将这个时间登记在日程表当中。这个日程表是整个频道当中人可见的。通过这种方式让你的用户提前知道所有的活动，通过这种方式提前预知，也是一个非常不错的方案。
