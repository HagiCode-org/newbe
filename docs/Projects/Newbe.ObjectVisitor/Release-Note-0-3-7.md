<!-- more -->

## 更新内容

原本，我们希望在 0.3 引入 mapper 或者 validation 其中之一。但是我们发现，我们需要完成更高层次的抽象才能更好的开展后续的工作。

因此。 0.3 版本我们完成了一个既酷炫又新奇，既引人深思又充满快乐的特性：

基于状态图自动生成任意设计的 FluentAPI。
