Amazing Favorites 0.5 UX 增强，改进了多处对于 Tag 操作的用户体验。并调整了底层存储结构，更加易于管理。

<!-- more -->

## 版本亮点

### 用户交互增强

#### 导入时自动 Tag

从收藏夹导入的链接，如果其存在父级文件夹，这些文件夹将会自动被添加为链接的 Tag。

#### 支持选择“打开新窗口”或者“激活已打开窗口”

在搜索页面中，直接点击连接，如果对应窗口已经打开，则会激活已打开的窗口。

若想要强制打开一个新的窗口，可以按住`ctrl`并点击链接以强制该操作。

#### 从已添加 Tag 中进行提示

添加 Tag 时将可以从已有的 Tag 中进行搜索和选择

![智能提示](/images/20210613-002.gif)

#### 弹出框添加 Tag 交互增强

添加新收藏时焦点自动切换到添加 Tag 文本框。

可连续添加 Tag。

逗号分隔字符串将会被视为添加多个 Tag。

![添加多个Tag](/images/20210613-003.gif)

### 结构性调整

#### 使用 IndexedDB 取代 storage

数据现在已经改为存储到 IndexedDB 中。将更有利于迁移和升级。

#### 更小的安装包

本体安装包从原有的 20M 下降到了 5M。加载速度也明显变快。
