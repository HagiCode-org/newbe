Dive. 国内直接从官网 https://github.com/OpenAgentPlatform/Dive/ 下载比较困难，需要一些技术手段。这里提供一个国内的镜像下载地址列表，方便网友下载。

Dive 是一个开源 MCP Host 桌面应用，目标是把支持函数调用能力的 LLM 与本地工具链连接起来，方便用户在桌面侧编排 Agent 工作流。
当前先按 AI Agent 工具链中的高价值仓库纳入镜像目录，优先保障安装包与更新资源的分发可达性。
这份说明属于可用的临时业务描述，后续仍可以继续根据产品定位和典型使用场景补充优化。
