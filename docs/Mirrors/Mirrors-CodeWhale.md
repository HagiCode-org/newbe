CodeWhale. 国内直接从官网 https://github.com/Hmbown/CodeWhale/ 下载比较困难，需要一些技术手段。这里提供一个国内的镜像下载地址列表，方便网友下载。

CodeWhale 是一个运行在终端里的 DeepSeek Coding Agent，适合偏好 TUI 交互、希望直接在本地命令行里完成代码助手工作流的用户。
项目使用 Rust 构建，并持续发布多平台二进制文件与安装包，比较适合纳入镜像目录做分发加速。
把这些 Release 资产接入镜像页后，国内用户下载 CLI 可执行文件和更新资源会更顺畅。
