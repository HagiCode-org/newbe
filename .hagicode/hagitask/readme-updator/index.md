# README requirements

## Product focus

- Introduce newbe as a Chinese-language technical site at https://newbe.hagicode.com where readers find .NET and cloud-native articles, tutorials, open-source project documentation and Chinese mirrors of open-source docs.
- Address readers and developers looking for those articles, tutorials and documentation mirrors. The README is written in Chinese; keep it in Chinese.
- Lead with what readers can find and a prominent link to the live site, not how the site is built or deployed.

## Required content

- Open with a short site introduction and the link to https://newbe.hagicode.com.
- Describe the content areas that exist in the site: short technical articles, tutorials, project documentation and open-source documentation mirrors.
- Point to the site's related-links page for community and contact entries instead of repeating them.
- Any command mentioned must match `package.json`.

## Exclusions

- Exclude tokens, secret values, internal hosts, machine-specific paths and private links.
- Keep repository maintenance instructions out of the README: repository layout, internal architecture, CI, build and deployment internals and contribution workflow.
- Do not list content areas the site does not show.
