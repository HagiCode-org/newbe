`newbe` 是一个中文技术站点，在 [newbe.hagicode.com](https://newbe.hagicode.com) 提供开源项目文档的中文镜像，方便快速查阅 .NET 与云原生相关的技术文档。

**在线阅读：[https://newbe.hagicode.com](https://newbe.hagicode.com)**

## 站点内容

- **开源镜像**：收录的开源项目文档中文镜像，方便快速查阅，例如 Dapr、k3s、minikube 等。

站点只发布 `docs/Mirrors` 下的镜像页面，以及首页、相关链接、隐私策略等固定页面。

## 社区与联系

QQ 群、微信公众号、Bilibili 等社区与联系入口，请见站点的[相关链接](https://newbe.hagicode.com/links)页面。
