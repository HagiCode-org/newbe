`newbe` 是一个中文技术站点，在 [newbe.hagicode.com](https://newbe.hagicode.com) 提供 .NET 与云原生相关的文章、教程、开源项目文档，以及开源项目文档的中文镜像。

**在线阅读：[https://newbe.hagicode.com](https://newbe.hagicode.com)**

## 站点内容

- **随笔**：简短的技术文章，记录 .NET 与云原生方面的实践与思考。
- **系列文章**：成体系的教程，例如依赖注入、IEnumerable、响应式编程、Tye 和个人博客搭建等主题。
- **开源小制作**：作者开源项目的文档，例如 Newbe.Claptrap、Newbe.Mahua、Newbe.ObjectVisitor 等。
- **开源镜像**：收录的开源项目文档中文镜像，方便快速查阅，例如 Dapr、k3s、minikube 等。
