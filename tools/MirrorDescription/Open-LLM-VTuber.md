Open-LLM-VTuber 是一个独特的语音交互人工智能伙伴。它不仅支持实时语音对话和视觉感知，还具有生动的 Live2D 虚拟形象。所有功能都可以在你的电脑上完全离线运行。
你可以把它当作你的个人人工智能伙伴，无论是想要虚拟女友、男友、可爱宠物或其他任何角色，它都能满足你的期望。该项目完全支持 Windows、macOS 和 Linux 操作系统，并提供两种使用模式：网页版和桌面客户端（特别支持透明背景的桌面宠物模式，可让人工智能伙伴在你的屏幕上任何地方陪伴你）。
虽然长期记忆功能暂时被移除（但很快会回归），但由于聊天记录的持久存储，你可以随时继续之前未完成的对话，不会丢失任何珍贵的互动时刻。
在后端支持方面，集成了丰富多样的大语言模型推理、文本转语音和语音识别解决方案。如果你想自定义你的人工智能伙伴，可以参考角色自定义指南来定制其外观和个性。
它被称为 Open-LLM-VTuber 而不是 Open-LLM-Companion 或 Open-LLM-Waifu，是因为该项目的初始开发目标是使用能在非 Windows 平台上离线运行的开源解决方案来重现闭源的人工智能虚拟主播 neuro-sama。
这个项目在 v1.0.0 版本后进行了代码重构，目前正在积极开发中，很快会有许多令人兴奋的功能推出！可以查看路线图了解更新计划。
